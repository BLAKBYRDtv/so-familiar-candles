# So Familiar Candles

Website for So Familiar Candle Co., hand-poured soy candles made to order.

- `index.html`: shop with collections, the "Make it yours" label designer, and the order form
- `craft.html`: how a candle is made, step by step
- `app.js`: products, sizes, prices and order handling (edit `PRODUCTS`, `SIZES` and `ORDER_EMAIL` at the top)
- `img/`: product photos; candle-making photos are from Pexels (free for commercial use)

Deploys as a static site on Cloudflare Pages: no build command, output directory `/`.
